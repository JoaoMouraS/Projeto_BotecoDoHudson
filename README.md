# Projeto Boteco do Hudson

Projeto desenvolvido para criar um site moderno e acolhedor para o Boteco do Hudson, reunindo informações sobre eventos, reservas, galeria de fotos e interação com os clientes.

## Sobre o projeto

O objetivo deste projeto é transformar o boteco em uma experiência digital completa, permitindo que os clientes conheçam o ambiente, acompanhem os eventos, reservem espaços e tenham acesso a conteúdos especiais do estabelecimento.

## Ideias e funcionalidades planejadas

### 1. Sistema de reservas
- Permitir que o cliente marque uma reserva informando a quantidade de pessoas.
- A reserva pode ter um número mínimo de participantes para ser efetivada, garantindo mais organização para o evento.
- Uma ideia futura é criar links específicos de reserva para cada evento ou comemoração, com a possibilidade de compra de ingressos ou confirmação de presença.

### 2. Galeria de fotos e reconhecimento facial
- As fotos tiradas no bar pelos fotógrafos podem ser enviadas para o site.
- O cliente poderá buscar suas fotos com a marca d’água do boteco.
- Caso queira a imagem sem marca d’água, pode ser oferecido um serviço extra com um valor sugerido de R$ 2,00 por imagem.
- O sistema também pode permitir a busca por Face ID ou foto do rosto, para localizar todas as fotos em que a pessoa aparece.

### 3. História e identidade do boteco
- O site pode contar a história do Boteco do Hudson para que os clientes conheçam mais sobre o local.
- Também pode incluir uma seção com a história dos funcionários, trazendo um toque humano e acolhedor.

### 4. Cardápio, eventos e comemorações
- Exibição dos pratos típicos e eventos futuros.
- Espaço dedicado para reservas de aniversários e comemorações especiais no local.

### 5. Atendimento e comunicação
- Implementação de um chatbot para atendimento via WhatsApp.
- Envio de notificações para clientes sobre eventos, confirmações e lembretes.
